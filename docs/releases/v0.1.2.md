### Clear errors when a call can't start

- If an outgoing call cannot start, the dial screen now says why instead of doing nothing.
  The most common reason is that the microphone or speaker could not be opened: the SIP stack
  opens the sound device before it contacts the PBX, so such a call never reaches it.
- On macOS the message offers a shortcut to the microphone permission.
- The log now lists the audio devices the app sees and the default input and output it uses
  (Settings → Diagnostics → Open log folder).

This is a diagnostic release: on some Macs outgoing calls still don't start. If that happens,
please send the message from the dial screen and the log file with your issue.

Downloads: `SilentSoftphoneFree-Windows-x64.zip` (Windows 10/11, 64-bit) and
`SilentSoftphoneFree-macOS-arm64.zip` (macOS 13+, Apple Silicon). Builds are not code-signed yet;
see the README for the first-launch steps.

### Українська

**Зрозумілі помилки, якщо дзвінок не стартує**

- Якщо вихідний дзвінок не вдається почати, екран набору тепер пояснює чому, а не мовчить.
  Найчастіша причина — не вдалося відкрити мікрофон чи динамік: SIP-стек відкриває звуковий
  пристрій до звернення до АТС, тож такий дзвінок до неї не доходить.
- На macOS повідомлення пропонує перейти до дозволу на мікрофон.
- Журнал тепер містить список аудіопристроїв, які бачить застосунок, і пристрої введення та
  виведення за замовчуванням (Settings → Diagnostics → Open log folder).

Це діагностичний випуск: на деяких Mac вихідні дзвінки поки не стартують. Якщо так сталося,
надішліть, будь ласка, текст повідомлення з екрана набору і файл журналу.

Завантаження: `SilentSoftphoneFree-Windows-x64.zip` (Windows 10/11, 64-біт) і
`SilentSoftphoneFree-macOS-arm64.zip` (macOS 13+, Apple Silicon). Збірки поки не підписані;
кроки першого запуску описано в README.
