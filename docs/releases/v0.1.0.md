The first public preview of Silent Softphone Free: a lightweight, free and open-source SIP
softphone for Windows and macOS.

### Downloads

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `SilentSoftphoneFree-Windows-x64.zip` — unzip and run `SilentSoftphoneFree.exe` |
| macOS 13+ on Apple Silicon (M1 and newer) | `SilentSoftphoneFree-macOS-arm64.zip` — unzip and move the app to Applications |

The builds are not code-signed yet. On Windows, SmartScreen may show **More info → Run anyway**.
On macOS, open **System Settings → Privacy & Security → Open Anyway** on the first launch.

### What's inside

- SIP over UDP and TCP; several accounts with one active
- Calls with hold, mute and DTMF (RFC 2833 with SIP INFO fallback), key tones
- Incoming call popup, live audio level meters, active codec
- Codec list with priorities (G.722, G.711 by default)
- Contacts, call history, tray icon, start with the system
- Light, dark and system themes; SIP log file

### Known limitations

- No TLS/SRTP yet; audio devices follow the system defaults; no ringtone yet
- macOS build is for Apple Silicon only

### Українська

Перша публічна попередня версія Silent Softphone Free — легкого, безкоштовного SIP softphone
з відкритим кодом для Windows і macOS.

**Завантаження**

| Система | Файл |
|---|---|
| Windows 10/11 (64-біт) | `SilentSoftphoneFree-Windows-x64.zip` — розпакуйте й запустіть `SilentSoftphoneFree.exe` |
| macOS 13+ на Apple Silicon (M1 і новіші) | `SilentSoftphoneFree-macOS-arm64.zip` — розпакуйте й перенесіть застосунок у «Програми» |

Збірки поки не підписані. На Windows SmartScreen може попросити **Докладніше → Виконати в
будь-якому разі**. На macOS при першому запуску: **Системні параметри → Приватність і безпека →
Усе одно відкрити**.

**Що всередині**

- SIP через UDP і TCP; кілька акаунтів, один активний
- Дзвінки з hold, mute і DTMF (RFC 2833 з переходом на SIP INFO), тони клавіш
- Спливаюче вікно вхідного дзвінка, шкали рівня звуку, активний кодек
- Список кодеків із пріоритетами (за замовчуванням G.722, G.711)
- Контакти, історія дзвінків, іконка в треї, автозапуск
- Світла, темна та системна теми; SIP-журнал

**Відомі обмеження**

- Поки без TLS/SRTP; аудіопристрої — системні за замовчуванням; без мелодії дзвінка
- Збірка для macOS лише для Apple Silicon
